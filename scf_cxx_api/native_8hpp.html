Detailed Description

XC functionals implemented natively (i.e., without LibXC or GauXC). Since they are templated C++ they work with the uncertainty-quantification (UQ) floating-point types, not just double.

simde::type::tensor scf::xc::native::svwn3_energy_density ( const simde::type::tensor &  rho_on_grid)

Computes the SVWN3 energy density, rho * (eps_x + eps_c).

Parameters
[in]rho_on_gridThe (total, spin-unpolarized) density evaluated on the grid points.
Returns
A tensor with the same shape and floating-point type as rho_on_grid.
Exceptions
std::runtime_errorif rho_on_grid's floating-point type is not supported. Strong throw guarantee.
std::domain_errorif any element of rho_on_grid could be zero or negative, but is not exactly zero. Exactly zero densities give the zero-density limit (zero). Strong throw guarantee.

Extracts the weights from grid and puts them in a tensor.

Unlike libxc::tensorify_weights, the weights are not assumed to be doubles. Instead they are extracted as the floating-point type of like.

Parameters
[in]gridThe grid whose weights are being extracted.
[in]likeA tensor holding the floating-point type to use.
Exceptions
std::runtime_errorif the weights of grid can not be retrieved as like's floating-point type. Strong throw guarantee.
