Attaches the uncertainty from incomplete convergence to an energy.

Called by an iterative method once it has converged. The result is the energy with uncertainty attached, e.g., from the change in the energy in the final iteration.

scf::property_types::DECLARE_PROPERTY_TYPE ( MOUncertainty  )

Attaches uncertainty to converged molecular orbitals.

Called by an SCF once it has converged. The orbital energies and coefficients are the eigenpairs of the converged Fock matrix in the metric of the overlap matrix. The result is the coefficients with uncertainty attached, e.g., from the uncertainty in the Fock matrix and from incomplete convergence.

Evaluates the quantity of another property type by quadrature.

Modules satisfying this property type evaluate the quantity computed by BasePT by quadrature on a grid they are given, rather than on a grid they build themselves. This lets the caller choose the grid, e.g., to evaluate the same quadrature on a finer grid to estimate the error of the grid. The inputs are those of BasePT plus the grid, and the results are those of BasePT.

Template Parameters
BasePTThe property type whose quantity is evaluated by quadrature, e.g., simde::aos_xc_e_aos for the XC potential.

Attaches uncertainty to the result of another property type.

Modules satisfying this property type are error models for the XC energy and potential, e.g., for the error from the incompleteness of the grid. They are given the inputs of BasePT and the results of calling a module satisfying BasePT with those inputs. The results are those of BasePT, but with uncertainty attached: each value is a UQ type whose nominal value is the corresponding value of the given results. The module satisfying this property type gets the UQ type from its own UQ Initializer submodule.

This property type is a stop gap. It should eventually replace SimDE's Uncertainty property type.

Template Parameters
BasePTThe property type of the module whose result is having uncertainty attached, e.g., xc_potential_quadrature.
